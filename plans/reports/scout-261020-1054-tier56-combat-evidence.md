# Tier 5/6 ultimate combat evidence

Scope: 25 heroes, excludes h01G Cộng Công. Ultimates and their resulting statuses/summons only. Phượng Hoàng lethal-triggered Niết Bàn is documented below only to distinguish it from the ultimate; passive egg/rebirth assets are outside the user-approved scope. Read-only source audit on 2026-10-20; no game, server, build or tests run. No art-quality acceptance inferred.

## Authority and shared contracts

- `content/catalog.ts` binds authored abilities and overrides h014 Nguyên Thủy to tier 6. `content/*-design.ts` supplies constants/prose; actual geometry below follows `packages/game-core/src/*-combat.ts` and `combat.ts`.
- Server broadcasts full `GameState` as snapshot (`apps/server/src/game-room.ts:93,111,136`), including `groundEffects`, unit/enemy statuses and summons. Keep persistent zones/statuses snapshot-driven, event effects transient.
- Every main ultimate uses `cast` + `skill-{heroId}` then an `ability` event with the same ID, except Thái Bạch's revive branch resolves only `trait/revive-h015`. Lobby resolves immediately and has no cast clock; several zones/summons differ there. Plan battle behavior first.
- Battle windup is .25s unless overridden: h01B .35, h015 .5, h03W .45, h03X .35, h01I .5, h01J .65, h014 .5, h040 .35. Cast target point/direction is locked in `pendingAbility`; several ultimates resolve centered on caster instead. Never derive hit geometry only from cast-event x/z.
- Hard control is probabilistic: tier 5 = 17% minion / 4% boss; tier 6 = 20% / 5%. Slows, pulls, knockback and armor break do not roll. `zoneControlled` rolls once per enemy per persistent zone. Use confirmed status snapshot for freeze/seal, not unconditional frost shells on every event target.
- Event `targets` often lists damage candidates, not successful controls or all healed allies. Per-recipient trait events can use each recipient's own zone. Do not assume all recipients share caster position/zone.
