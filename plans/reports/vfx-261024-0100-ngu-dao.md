## Root integration APIs

- `new VisualNguDao(scene)` implements HeroVfx; exact tier3-tier4-h00Y cast/ability. `extra.targets` true enemies, `extra.supportTargets` actual allied unit positions. Shared statuses retain gameplay ownership.
- `markShackle(id,at,remaining,reduced)`, `markPair(id,from,to,remaining,reduced)`, `markFrenzy(id,at,remaining,reduced)`: root calls before tick every frame for exact owned state. Pair key may be `${casterId}:${group.join('|')}:${a}:${b}`. No inferred statuses or spawn-on-reconnect action replay.
- `pulsePair(pairId,reduced):boolean` is optional hit-event presentation only: call for real damage/link hit events. Markers and tick never schedule recurring pulses. No hit event means no traveling ghost pulse. Pulse lasts .34s and follows current actual endpoints. Do not duplicate game damage.
- `replay(origin,aim,reduced,kind='ultimate'):boolean` creates explicit client-only preview targets,5s snapshot markers and one synthetic hit pulse; unsupported kind/invalid vectors/caps return false.
- `tick(dt,time)` updates actual shader uTime, retains current cold-load phases and retries mesh acquisition, updates existing braid buffers/endpoints, then closes missing markers. Reduced motion uses uTime0, fixed sheet phase/pose and no spray or endpoint travel; alpha exit remains.
- `clear()` cancels cast entries/watchdogs, pending replay callbacks, previews, pair pulses and markers; releases painted planes, chain meshes, shader layers and kit bank work. Cached disabled meshes/materials remain bounded and reusable.
